# DLnotebook

双击 **`启动客户端.bat`**（需先装 Node.js）→ 浏览器自动打开 `http://localhost:8080`，选关开玩。

---

**给 AI 协作者（人可跳过）**

动手之前请先读 **`AGENT.md`**——它是本项目的**唯一事实来源**：目标与硬约束、技术栈取舍、
文件结构、数据契约摘要、工具链、**当前进度**、决策记录（ADR）、已知问题与风险、下一步。
需要细节再往下读 `docs/`：

- `docs/level-format.md` —— `level.json` 格式规范（客户端与生成器之间的契约，"宪法"）
- `docs/client-impl.md` —— 客户端**当前实际实现**（与设计稿 `client-spec.md` 冲突时以它为准）

三条硬约定：

1. **每次改动项目后，必须同步更新 `AGENT.md`**（「当前进度」「决策记录」「已知问题」三节尤其重要）。
2. 代码注释、文档、给发起人的说明一律用**中文**，并解释"为什么"，不能只说"怎么做"。
3. 发起人**零编程基础**，不学编程：他的配合方式是运行程序、描述现象、贴报错、试玩提反馈。
   任何需要他动手的步骤，都要写成"双击哪个文件、看到什么、点哪里"。
