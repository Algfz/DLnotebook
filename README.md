# DLnotebook

**手机上玩（2026-10-19 起的开发主环境）**

在项目根目录跑 `node tools/dev-server.js 8080`（或直接 `sh 启动手机端.sh`），手机 Chrome 打开 `http://127.0.0.1:8080` → 选关开玩。**完整步骤与常见问题见 [`手机启动说明.md`](手机启动说明.md)**。
**手机横过来玩**（关卡是按 16:9 横屏设计的，点 Play 会自动全屏并转横屏）。
**点屏幕转向**；双线关卡里**右半屏 = 白线、左半屏 = 黑线**。

> 竖屏的取景距离可现场调：地址后面加 `?fit=1.2`（1 = 完全不后撤，数字越大机位越远）。

**电脑上玩**

双击 **`启动客户端.bat`** → 浏览器自动打开 `http://localhost:8080`，选关开玩。

> 不再打包 exe 了（决策见 `AGENT.md` 的 ADR-23）——浏览器本身就是客户端。

**第一次跑（给朋友 / 换电脑）**

1. 装 **Node.js**（选 LTS）：<https://nodejs.org/zh-cn> —— 一路"下一步"，默认选项即可
2. 双击 `启动客户端.bat`
3. 浏览器自动打开 `http://localhost:8080`

- **没装 Node 也能跑**：脚本会自动改用 Python 起静态服务器（玩法一样，只是没有请求日志和手机端打点）。
- 两个都没有时，窗口里会**直接写出下载地址和步骤**，不会再只丢一句 `'node' 不是内部或外部命令`。
- 手动起也行：`node tools/dev-server.js 8080`（Node 18+，**零 npm 依赖，不用 `npm install`**）。
- ⚠️ 别用 UTF-8 编辑器另存 `启动客户端.bat`：它必须是 **GBK + CRLF**，否则 cmd 会把中文行拆碎、报一堆"不是内部或外部命令"。

**给 AI 协作者（人可跳过）**

动手之前请先读 **`AGENT.md`**——它是本项目的**唯一事实来源**：目标与硬约束、技术栈取舍、
文件结构、数据契约摘要、工具链、**当前进度**、决策记录（ADR）、已知问题与风险、下一步。
需要细节再往下读 `docs/`：

- `docs/level-format.md` —— `level.json` 格式规范（客户端与生成器之间的契约，"宪法"）
- `docs/client-impl.md` —— 客户端**当前实际实现**（与设计稿 `client-spec.md` 冲突时以它为准）

三条硬约定：

1. **每次改动项目后，必须同步更新 `AGENT.md`**（「当前进度」「决策记录」「已知问题」三节尤其重要）。
2. 代码注释、文档、给发起人的说明一律用**中文**，并解释"为什么"，不能只说"怎么做"。
3. 发起人**零编程基础**，不学编程：他的配合方式是运行程序、描述现象、贴报错、试玩提反馈。
   任何需要他动手的步骤，都要写成"双击哪个文件、看到什么、点哪里"。
