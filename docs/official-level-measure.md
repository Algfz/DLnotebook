## 4. 沿路关系（单位 = 通道开口 W）

`tools/refprops.py`（逐帧）：

1. 路面：`rf.road_mask_kmeans(img,k=6,tol=34)`（色簇连通域须触底边、底边交点居中 0.22~0.78，按 周长²/面积 取最优）。
2. 上方向/地面：`ground_up` + 路面点中位高度。
3. 路面系：`u = (P−d·n)·r / W`、`v = (P−d·n)·f / W`、`h = (P−d·n)·n / W`（`r,f,n` 由相机 z 轴与 up 张成）。
4. 道具：**非地面、非路面**色簇的连通域（形态学开闭）→ 世界空间按 u/v 重叠合并（同一物件的受光/背光面会被色簇切开）→ 丢弃 `h<0.12W`（阴影/地面色块）。
5. 单位：`unit = open_m`（**通道开口**：右侧道具左内缘 − 左侧道具右内缘，米；需每侧 ≥2 件），退化时用路面掩膜宽 `W_m`。
   原因：路面掩膜常只覆盖路带的一部分（红带的亮/暗两半），`W_m` 系统性偏小；而道具内侧贴路，开口才是"可走宽度"。
6. 产出：`out/tmp/props/<tag>-props.jsonl`（逐帧每件：u/v/u_span/v_span/h/bbox/overlay）、`<tag>-summary.json`（p5/25/50/75/95）、`index.json`；
   浏览页 `tools/props-review.html`（俯视散点 + 逐帧曲线 + 分布表 + 叠加图）。

**已知偏差（必须和数字一起看）**：

- 路面掩膜的绝对宽度偏小（色带被切成多块）⇒ `W_m` 只作诊断；`open_m` 更可靠但仍受"道具是否贴路"影响。
- MoGe 的尺度/倾斜有残差（27% 像素落在拟合地面之下）⇒ 高度用"本件自身底面"作基准，并按 `median_filter(31×31)` 去趋势。
- 近距离道具会被画面边缘裁切 ⇒ `u_span/v_span` 偏小；远处道具被合并成一个大块 ⇒ 偏大。
- 动态物体（碎裂/特效/运动平台）在此管线里= 普通连通域，**未做动/静分离**。

## 5.4 可信度分级（必须和数字一起看）

| 结论 | 可信度 | 依据 / 风险 |
|---|---|---|
| 地面方向、地面平面（相机高） | **高** | 用我们引擎真值测过：up 误差 4.7° |
| 相对几何（谁在谁旁边、比例） | 中 | 主轴/尺度有 ±30% 压缩 |
| 速度（W/s） | **低-中** | 三个窗口 1.97~3.90 差 2 倍；主因是**路宽 W 每帧抖动**（掩膜只覆盖路带一部分）。修法：整窗用"掩膜面积达标帧"的中位 W，或直接用道具内缘的通道开口 |
| 折点/偏航率 | 低 | 光流+相似变换的离群未剔除（\|p95\| 46°/s 属异常），且沙漠中段有动态段 |
| 道具尺寸（W） | 低-中 | 三个窗口一致（好信号），但检测口径是"高出局部地面"，**会把岩石/地形也算成道具**；阴影问题已由"几何优先"解决 |
| 绝对尺度（米） | **不可信** | MoGe 绝对尺度误差大；一律用比值 |

## 6. 下一步（按优先级）

1. **路宽 W 的稳健估计**（当前最大误差源）：整段用"掩膜面积达标帧"的中位 W；或用左右道具内缘的通道开口；或用 VGGT 点云把路面点投影后量宽度。
2. **动/静分离**：多帧一致性把"会动的东西"（平台/碎裂/特效）挑出来，先剔除再做运动学与道具统计。
3. **离群剔除**：光流跟踪要求内点数 ≥N、残差 ≤ε；相邻样本的速度/偏航率变化超阈值就直接丢。

### 7.2 三个坑（都是"卡死或算错"级）

| 现象 | 原因 | 修法 |
|---|---|---|
| 整关融合 15 分钟不出结果 | `np.load()` 返回**惰性** `NpzFile`，逐点索引 `za["uvf"][i]` 每个点都重解压整段数组 | 进循环前一次性物化到 dict |
| `voxel_down()` 44 分钟 CPU 不收敛 | `np.unique(key, axis=0)` 在千万级点上极慢 | 三轴体素坐标打包成 int64 再 `unique`（21 bit/轴） |
| 测出的运动只有 0.19 单位/秒（错） | 特征点坐标要求整除 step 的过滤把内点几乎全滤掉，且空数组触发 `AxisError: axis 1 is out of bounds` | 改"最近栅格"（误差 ≤ step/2 像素）+ `len(uva) < 12` 提前返回 ⇒ **2.48 单位/秒**，与 `refmotion.py` 一致 |

### 7.4 还没做的（可信度仍受限）

- **绝对尺度**：MoGe 把尺度压缩约 4 倍（相机高实测 ≈2.4~2.8 单位，路宽 W≈0.09~0.30 单位）⇒ 一切数字只给"以 W 为单位"的比值。
- **对齐精度**：帧间只有 2D 相似变换（地面系光流），长距离会漂；顶视图的扇形/鱼骨纹就是证据。升级路径 = ICP/TSDF 或真位姿。
- **运动学离群**、**特效时间线**、**路宽 W 的稳健估计** 仍是 §6 的待办。
