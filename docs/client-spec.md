## 一、启动与关卡发现

```
启动 → 扫描 levels/ 下每个子目录 → 读取其中的 *.level.json → 生成关卡列表
```

- 子目录名即关卡标识；目录内应含 `level.json`、音乐文件、`cover.png`（可选）
- 读取失败或格式不符的关卡，跳过并在列表中给出提示（不要崩溃）
- 关卡列表按目录名排序（后续可加自定义排序字段）

## 四、音画同步（最关键）

### 原则：音频主时钟

```js
// ✅ 正确：位置由音频时间直接算出
const t = audioCtx.currentTime - startTime - latency;
const s = t * speed;              // 走过的路程
const pos = pathAtDistance(s);    // 纯函数：路程 → 坐标

// ❌ 错误：逐帧累加，误差会累积
position += speed * deltaTime;
```

**为什么**：音频硬件时钟是"真相"，渲染帧时钟不准。累加会让音画越走越偏，而纯函数计算**误差无处累积**——掉帧只让画面卡，绝不会音画错开。

### 补偿机制（预卷）

```js
const L = latency / 1000;
songTime = clamp(playOffset + (AC.currentTime - playCtxT0) - L, playOffset, duration);
```

- `latency` = **音频输出延迟 + 人的反应时间**（毫秒）
- 点播放后**音频立即响，画面延后 L 毫秒才启动**——这就是"预卷"
- 下界取 `playOffset`，避免补偿期内播放头倒退
- 同一值同时作用于**画面**与**打点位置**，保证"所见即所得"

### 精度增强（可选）

`AudioContext.getOutputTimestamp()` 提供音频帧在两个时间轴的对应关系，比 `currentTime` 更精确：

```js
const { contextTime, performanceTime } = ctx.getOutputTimestamp();
const heardTime = contextTime + (performance.now() - performanceTime) / 1000;
```

### 校准

- 关卡自带 `latency_ms` 作默认值（作者校准值，本关 299ms）
- 游戏内可实时调整，存入 localStorage（每设备独立）
- 手动微调快捷键：`Alt+,` / `Alt+.`（∓10ms）——⚠️ **尚未在客户端实现**（仅采音器有）
- ✅ **游戏内校准器已实现**（2026-10-11）：与采音器同一套「蜂鸣 + 空格」算法，
  弹窗里同时显示本关作者校准值作参考。详见 `client-impl.md` §十二

## 五、渲染要点

| 项 | 做法 |
|---|---|
| **路面** | 沿 path 生成带状 mesh（宽度可配置），段间用直角连接 |
| **线** | 沿路径运动的发光几何体，转弯处可做圆角插值（视觉平滑，判定仍按几何） |
| **装饰** | **必须**用 `InstancedMesh`——同类道具一次绘制上千实例，否则上万个物体会卡死 |
| **天空/雾** | 每幕按 `theme` + `palette` 设置 |
| **后期** | bloom / 色差 / 暗角，按 `fx` 时间轴调强度 |
| **死亡** | 撞障碍或掉出路面 → 短暂动画 → 从最近检查点重开 |

## 七、打包与分发

遵循社区圈的打包惯例：

```
我的关卡_v1.0.zip
└─ 我的关卡/                  ← 解压得到目录
   ├─ 我的关卡.exe            ← 与目录同名，双击即玩
   ├─ resources/
   │   └─ app.asar            ← 客户端代码
   │       └─ levels/         ← 关卡目录
   └─ ...（Chromium 运行时）
```

**关键点**
- exe 名必须与所在目录名**一致**（发起人明确要求）
- 版本号只体现在压缩包名上（`xxx_v1.0.zip`），解压出的目录不带版本号
- 更新关卡时两种发法都支持：重发完整包，或只发新的关卡目录让玩家丢进 `levels/`

## 八、实现顺序建议

1. **骨架**：Electron 壳 + 关卡扫描 + 选关界面（先能列出关卡）
2. **核心**：Three.js 渲染路径 + 线运动 + 音频时钟驱动（先出几何风格，不看效果）
3. **玩法**：转向输入、死亡、重开、检查点
4. **分幕**：theme 切换、装饰铺陈、镜头、fx
5. **UI**：设置、引导线、延迟调整、关卡首帧
6. **打磨**：视觉、性能、打包

> 建议第 2 步先用**线框/纯色几何**跑通，确认"音画同步 + 手感"正确后，再堆视觉效果。
