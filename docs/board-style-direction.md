**核心思想：一种材质造一座世界。** 一个平面 + 顶面材质 + 侧面材质 + 摆放长方体，就能表达
平地 / 悬崖 / 峡谷 / 碎片 / 柱林；**地形变化靠减法（在板上切槽），不靠加法。**

## 实现落点

- `src/js/terrain.js`：`motifBoard()`（`slot===0` 铺整块板；`slot>0` 按 `motifCanyon` 的结构挖槽）、
  `DEFAULT_PARAMS.board` / `.boardSlot`、`PALETTES.board`。
  ⚠️ `splitRuns` 会把"母题名 + 色卡都相同"的相邻段合并（段内取第一段 params），
  所以"切了槽的那一段"**必须另起一个母题名**（`boardSlot`）。
- `src/js/game.js`：`THEME.board`；雾距可被关卡覆盖：`scenes[0].fogRange = [near, far]`。
  雾要近（本关 26~118 m），远处板面溶进天空，画面里才没有地平线。
- `src/js/props.js`：`PROP_COLORS.board`；五件纯长方体 `slabB` / `wallB` / `pillarB` / `cubeW` / `dotB`；
  `PROP_R`、`SHADOW_R`（那关没有投影，我们只留很小的浅影）、`FLAT_OF`（`board`/`boardSlot` → `half-2`）。
- 关卡重建脚本：`out/_rebuild_board.cjs`（只改 `terrain` / `scenes[0]` 的主题与雾 / `props`）。
- 提交：`28ffaa4`。

## 摆件的两条经验（都是渲染出来才发现的）

1. **相机在路的后方**（跟距 ~30 m）：贴路（`off < 11 m`）的高柱正好挡在相机与路之间，
   会把路埋成一条深井。近路一档要**压低压矮**，柱林退到 11 m 以外，留出"路廊"。
2. **接地影在浅色板上会变大灰水洼**：`SHADOW_R` 对板式摆件要压到 1 m 以内，
   `shade` 色要贴近板面（`#BCC0C9`），否则画面会脏。
